# Bienvenido a la Expo app 👋

Este es un proyecto en  [Expo](https://expo.dev) creado con  [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

##  Descripción

Una aplicación móvil desarrollada en React Native y el SDK 54

## Instalación y Uso

Sigue estos pasos para ejecutar el proyecto en tu entorno local:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/dieguin232323/test_react.git
   ```

2. Instalar dependecias

   ```bash
   npm install
   ```

3. Ejecutar la aplicación

   ```bash
   npx expo start
   ```
